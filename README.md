# حساب الصراف الذكي 🏦 (Smart Teller Account)

تطبيق ويب سحابي متكامل لإدارة الحسابات، الحوالات، الأرباح، والمصاريف بالدينار العراقي، مصمم خصيصاً ليكون بسيطاً للغاية ومناسباً لكبار السن، ومزود بأتمتة كاملة لإرسال كشوفات الحساب بصيغة PDF عبر الواتساب تلقائياً ومزامنة البيانات عبر الهواتف والكمبيوتر.

---

## الميزات البرمجية

1. **دخول آمن للغاية بخطوتين**:
   * فحص كلمة المرور الرئيسية الصعبة.
   * إرسال رمز تحقق مؤقت (OTP) إلى واتساب صاحب الحساب تلقائياً للدخول الآمن.
2. **إدارة الزبائن والعمليات بالدينار العراقي**:
   * إضافة زبائن وإجراء عمليات إيداع (ينطيني) وسحب/حوالات (ياخذ).
   * إدخال عمولة/ربح الصراف لكل عملية.
   * تأكيد حماية ذكي بألوان متباينة لمنع الأخطاء أثناء إدخال المبالغ.
3. **أتمتة الواتساب والكشوفات (مجاني 100%)**:
   * إرسال كشف PDF كامل للزبون بكبسة زر واحدة من الهاتف دون تدخل يدوي.
   * إرسال تلقائي ومجدول بالخلفية كل أسبوع (يوم الجمعة 8 مساءً) للزبائن النشطين.
   * إرسال ملخص نصي سريع بالواتساب كخيار إضافي.
4. **المصاريف والأرباح**:
   * إدارة مصاريف المحل وحساب صافي الربح الكلي.
5. **نسخ احتياطي وحفظ سحابي**:
   * البيانات مخزنة في قاعدة بيانات Firebase السحابية، مما يضمن أمانها 100% ومزامنتها الفورية بين الآيفون والاندرويد والكمبيوتر.
   * حفظ جلسة الواتساب سحابياً ليتصل تلقائياً ولا يتطلب مسح الـ QR إلا مرة واحدة فقط.

## إعداد الأمان (إلزامي قبل التشغيل)

الخادم **يرفض الإقلاع** إذا لم تُضبط هذه المتغيرات — لا يوجد أي كلمة مرور افتراضية.

1. ولّد كلمة المرور المشفّرة ومفتاح الجلسات:

```
node backend/scripts/hashPassword.js "كلمة-المرور-الجديدة"
```

2. انسخ السطرين الناتجين إلى ملف `.env` (وإلى متغيرات البيئة في Render):

* `ADMIN_PASSWORD_HASH` — كلمة المرور مشفّرة بـ bcrypt.
* `JWT_SECRET` — مفتاح توقيع الجلسات (٦٤ خانة عشوائية على الأقل).
* `OWNER_PHONE_NUMBER` — رقم المالك لاستقبال رمز التحقق. إذا تُرك فارغاً يُعطَّل التحقق بخطوتين.
* `ALLOW_LOGIN_WITHOUT_OTP` — للطوارئ فقط عند تعطّل الواتساب. اتركه `false`.

كل مسارات `/api` محمية بتوكن موقّع وصالح ١٢ ساعة، عدا تسجيل الدخول وكشف الحساب المشترك وفحص الحالة.

## طريقة التشغيل المحلي (التطوير والتجربة)

1. تأكد من تثبيت [Node.js](https://nodejs.org/).
2. افتح مجلد المشروع واصنع ملف بيئة باسم `.env` بناءً على الملف التوضيحي `.env.example`.
3. لتشغيل السيرفر الخلفي (Backend):
   ```bash
   node backend/server.js
   ```
4. لتشغيل الواجهة الأمامية (React):
   ```bash
   npm run dev
   ```
   *(سيفتح التطبيق على الرابط المحلي المعروض في التيرمينال).*

> **ملاحظة**: في حال عدم وضع بيانات Firebase في ملف `.env`، سيعمل التطبيق تلقائياً في **وضع التشغيل المحلي الموفق (Offline Fallback)** ويحفظ البيانات في ملف `backend/data/database.json` محلياً لتسهيل التجربة الفورية.

## طريقة الاستضافة السحابية الكاملة (Render & Firebase)

لكي يعمل الموقع 24/7 على هاتفك والكمبيوتر بدون الحاجة لتشغيل جهازك الشخصي كسيرفر، اتبع الخطوات التالية:

### 1. إعداد Firebase السحابي
1. اذهب إلى [موقع Firebase](https://console.firebase.google.com/) وأنشئ مشروعاً جديداً مجانياً.
2. أنشئ قاعدة بيانات **Firestore Database** في وضع الإنتاج (Production Mode).
3. من إعدادات المشروع (Project Settings) 🡨 حسابات الخدمة (Service Accounts)، قم بتوليد مفتاح خاص جديد (Generate New Private Key) ونزّل ملف الـ JSON. ستحتوي هذه البيانات على مفاتيح الاتصال للسيرفر الخلفي.
4. أنشئ تطبيق ويب في الفايربيس للحصول على مفاتيح الواجهة الأمامية (`VITE_FIREBASE_...`).

### 2. رفع واستضافة التطبيق على Render.com
1. ارفع مجلد المشروع على حسابك الخاص في **GitHub**.
2. سجل دخول في موقع [Render](https://render.com/) وأنشئ خدمة ويب جديدة (**Web Service**).
3. اربط مستودع الـ GitHub الخاص بك بالمشروع.
4. قم بضبط إعدادات الاستضافة كالتالي:
   * **Root Directory**: اتركها فارغة (أو `./`).
   * **Build Command**: `npm install && npm run build`
   * **Start Command**: `node backend/server.js`
5. اذهب إلى تبويب المتغيرات البيئية (**Environment Variables**) وأضف المتغيرات المذكورة في ملف `.env.example` الخاص بك.
6. اضغط على **Deploy** وسيعطيك موقع Render رابطاً سحابياً مشفراً ومجانياً يفتح من أي هاتف في العالم!

### 3. الحفاظ على استيقاظ السيرفر (Uptime)
بما أن ريندر يضع السيرفر في وضع النوم بعد 15 دقيقة خمول في الخطة المجانية، اذهب إلى موقع [UptimeRobot](https://uptimerobot.com/) (مجاني) وأضف رابط موقعك الذي حصلت عليه من Render ليفحصه كل 5 دقائق. هذا سيضمن بقاء البوت ومجدول الرسائل مستيقظين طوال الوقت مجاناً!

## طريقة ربط الواتساب لأول مرة
1. افتح رابط موقعك السحابي من الهاتف أو الكمبيوتر وسجل الدخول.
2. اذهب إلى تبويب **إعدادات البوت والواتساب**.
3. سيظهر لك رمز QR كود (مثل واتساب ويب).
4. افتح الواتساب في هاتفك 🡨 الأجهزة المرتبطة 🡨 ربط جهاز، وامسح الكود.
5. بمجرد ظهور كلمة **"متصل بنجاح"**، تم كل شيء! سيحفظ النظام الجلسة سحابياً ولن تحتاج لإعادة المسح مجدداً.
